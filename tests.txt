Тест 1:
Исходные данные: item = {101, "Pen", 3, 20}
Ожидаемый результат:
101 Pen 3 20
Cost = 60
New cost = 100
Фактический результат:
101 Pen 3 20
Cost = 60
New cost = 100
Статус: совпало

Трассировка переменных для Теста 1:
1. Инициализация структуры: item.id = 101, item.name = "Pen", item.quantity = 3, item.price = 20.
2. Первый вывод: printf печатает поля через точку -> "101 Pen 3 20".
3. Вызов cost(item): в функцию передаётся копия записи x (x.quantity = 3, x.price = 20). Выполняется приведение (long long)3 * 20 = 60.
4. Вывод первой стоимости: "Cost = 60".
5. Изменение поля: item.quantity += 2 -> теперь item.quantity = 5 (остальные поля не изменились).
6. Повторный вызов cost(item): передаётся копия с x.quantity = 5 и x.price = 20, возвращается (long long)5 * 20 = 100.
7. Вывод новой стоимости: "New cost = 100".

Тест 2 (проверка нулевого количества):
Исходные данные: item = {101, "Pen", 0, 20}
Ожидаемый результат: Начальная стоимость Cost = 0, после увеличения на 2 -> New cost = 40
Фактический результат: Cost = 0; New cost = 40
Статус: совпало
